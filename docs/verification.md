# 开发预览验证记录

## 2026-10-02：无子会话查询修复

本机复现 WTSGetChildSessionId 返回 FALSE，GetLastError 为 1168（ERROR_NOT_FOUND），输出 ID 为 ULONG(-1)。现在将此错误码归一化为无子会话；权限拒绝、不支持和 RPC 故障仍抛出原始错误。增加三个回归场景，包含创建前和注销后返回 1168 的完整模拟生命周期，共 9 项测试通过。真实桌面连接仍需与会话实际运行验证区分。

日期：2026-10-01。

## 环境

- Windows 11 专业版 x64，Build 26200。
- .NET SDK 10.0.401，安装在项目 `.tools/dotnet`，实测约 770 MiB。
- 自包含 win-x64 发布目录约 171 MiB，无需另装 .NET 运行时。
- 源码为基于 Microsoft Learn 公开接口独立编写，未引入第三方项目代码。

## 已验证

- Release 编译：0 警告、0 错误。
- 6 项会话生命周期测试：未知已有会话必须确认、查询失败不新建、连接成功必须有会话 ID、合并重复启动、目标变化时禁止注销、取消后释放操作锁。
- 系统 RDP ActiveX 控件可创建，ConnectToChildSession 和其他首版连接属性可设置。
- 系统会话能力与会话 ID 可读取。检测到已有子会话；未连接、修改或注销它。
- 窗口初始化与首页预览检查。

## 待真实会话验证

- 首次启用时的权限与 UAC，实际登录、连接与注销。
- 最小化后恢复、断线后手动重连、进程崩溃后确认恢复。
- 多 DPI、多屏、中文输入法、声音与系统组合键。
- 睡眠恢复和 Windows 关机、注销场景。

## 首版限制

- 使用普通任务栏窗口，不提供托盘或全局快捷键。
- 分辨率在启动连接时读取主显示器像素尺寸；窗口缩放不修改分身分辨率。
- 声音与系统组合键设置在下一次连接时生效。
- 断线后手动重连，未实现自动重连策略。
- 提权通过用户点击后由系统 UAC 重新启动主程序，尚未拆分权限辅助进程。
- 暂无安装器、签名和自动更新。
